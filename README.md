# Muthammal V Portfolio

A premium, modern, and fully responsive personal portfolio website built with only HTML, CSS, and JavaScript.

## Folder Structure

- `index.html`
- `assets/css/style.css`
- `assets/js/script.js`
- `assets/images/profile.jpg`
- `assets/images/bridal-project.png`
- `assets/images/iot-project.png`
- `assets/resume/Muthammal_V_Resume.pdf`
- `assets/icons/favicon.ico`

## Notes

- The page uses relative paths so it can be deployed directly to GitHub Pages, Netlify, or Vercel.
- Replace the placeholder media files in `assets/images`, `assets/resume`, and `assets/icons` with your actual assets.
- Font Awesome and Google Fonts are loaded from their CDNs.

## Features

- Sticky navigation
- Smooth scrolling
- Typing animation
- Scroll reveal animation
- Animated skill cards
- Dark and light mode toggle
- Back to top button
- Contact form validation
- Glassmorphism UI
- Responsive layout

## Deployment

This repository is ready to be pushed to GitHub and deployed to services like Render, Netlify, or Vercel. Replace placeholder assets with production-ready files before public deployment.
